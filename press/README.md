# Press & Media Center

Static page content for the existing SBF WordPress shell. Keep the live header, navigation, footer, and donation experience; none are reimplemented here.

## Maintenance
Edit coverage.json (21 unique stories), page.template.html, styles.css, or filters.js.
Run `node press/build.mjs` from the repository root to regenerate index.html.
No dependencies or runtime data fetches. All coverage remains available without JavaScript; filters progressively enhance it.
The three featured stories also appear in the complete archive. Mixed-format stories can appear under both relevant filters.
styles.css is standalone and includes the SBF tokens, typography and button styles used by this page. No second local stylesheet is needed. Poppins is loaded from Google Fonts, with Arial/sans-serif fallbacks.

## Preview
For editors with three code slots, paste the contents of slots/press.html, slots/press.css and slots/press.js into the corresponding slots. These are generated by build.mjs. Do not add style/script tags or stylesheet links. HTML includes its own SBF wrapper, not a second document body. Set page title, description and canonical URL in your CMS SEO settings; see page.template.html for their values. JavaScript supports execution before or after DOM readiness and guards against duplicate initialization.

Run `python3 -m http.server 8000 --bind 127.0.0.1` and visit http://127.0.0.1:8000/press/.
WordPress template integration and its global navigation need a separate staging check before publication.
