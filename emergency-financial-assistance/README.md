# Emergency Financial Assistance page

Use the existing WordPress page and slug:

`emergency-financial-assistance`

## WordPress setup

1. Keep the existing site header, footer, analytics, and cookie-consent configuration.
2. Set the page template to the same full-width template used by the other custom SBF pages.
3. Paste the `<main class="sbf-efa-page">` block from `index.html` into a Custom HTML block.
4. Paste the complete contents of `styles.css` into the page-level CSS field or WordPress Additional CSS.
5. Set the SEO title to `Emergency Financial Assistance | Social Butterflies Foundation`.
6. Set the meta description to:

   `Learn about emergency financial assistance from Social Butterflies Foundation for eligible Virginia residents living with lupus or fibromyalgia. Review eligibility requirements and apply online.`

7. Confirm the page is indexable and does not have a `noindex` directive.
8. Confirm every application button opens the official Google Form in a new tab.

No JavaScript or new dependency is required.
