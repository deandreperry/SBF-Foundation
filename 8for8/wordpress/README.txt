WORDPRESS COPY-AND-PASTE FILES

1. Create a page with the slug 8for8. Use the existing full-width template and
   retain the site's header and footer. Hide the automatic page title if it
   duplicates the campaign heading.
2. Paste 8for8.html into a Custom HTML block or your builder's HTML field.
3. Paste 8for8.css into the page's CSS field or WordPress Additional CSS.
   Do not include <style> tags in a CSS field.
4. Paste 8for8.js into a JavaScript field/snippet configured to run on this page.
   Do not include <script> tags in a JavaScript field. If the editor only has
   an HTML field for JavaScript, wrap the JavaScript in <script>...</script>.
5. Preview the page and verify the Zeffy donation form before publishing.

Use all three files together. The HTML is a page-content fragment, without
<html>, <head>, <body>, stylesheet links, or script tags. The JS file loads
Zeffy's official script and contains its error fallback. WordPress must allow
iframes and the JavaScript snippet to run. Do not also paste the standalone
8for8/index.html or load a second copy of the Zeffy script.
