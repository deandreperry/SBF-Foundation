# $8 for 8 Years

Dedicated anniversary campaign at `/8for8`, active through November 30, 2026.
Static HTML/CSS, matching the repository's directory-based routing and standalone
page conventions. No dependencies, payment implementation, or analytics provider added.

## Files and design

- `index.html`: metadata, hero, live campaign progress, Why $8, four verified impact
  blocks, donation choices, official Zeffy embed/fallback, recurring explanation,
  and final mission/CTA.
- `styles.css`: scoped SBF Poppins typography, existing color tokens, 1180px
  container, pill buttons, 8px corners; responsive campaign layouts.
- `campaign.js`: labels the iframe generated by Zeffy's v2 script. It does not
  inspect the cross-origin form, preselect options, handle payments, or track donors.
- Homepage `index.html` and `styles.css`: a compact campaign teaser after the hero,
  linking to `/8for8`. No existing anniversary teaser existed in this checkout.

Program content comes from `programs/index.html` sections `support-group`,
`emergency-financial-assistance`, `care-outreach`, and `youth-scholarship`.
No impact statistics, testimonials, or donation totals were invented.

## Preview and production integration

Run `python3 -m http.server 8000 --bind 127.0.0.1` at the repository root.
Visit `http://127.0.0.1:8000/8for8`. The static server resolves this to `/8for8/`.
The canonical remains `https://socialbutterfliesfoundation.org/8for8`.

This repository contains page content, **not the live WordPress theme or deployment
configuration**. As with the existing Press page, retain the live header,
navigation, footer, and WordPress layout when publishing:

1. Create the WordPress page with slug `8for8` using its existing full-width page
   template. Avoid a duplicate theme-generated page title or main landmark.
2. Insert the content inside this HTML document's body into a
   `<div class="sbf-campaign-page">` wrapper. Do not paste a second document body
   into the theme. If the template already owns the main landmark, use a `div`
   for this content's `main` element.
3. Enqueue this campaign stylesheet and the deferred campaign script only on this
   page, adjusting their asset URLs to the deployed locations. Allow the official
   Zeffy script and iframe attributes through the CMS editor. Preserve its exact
   error handler; a CSP must permit it or it must be attached by an allowed script.
4. Apply the title, description, canonical and Open Graph fields from the document
   head using the existing CMS SEO system. No campaign image exists in the project;
   add `og:image`, dimensions and alt text only after an approved image is available.
5. Publish the homepage teaser update and verify the full WordPress shell on staging.

No live theme navigation/footer, analytics integration, or hosting credentials are
available here. Therefore live deployment, global mobile navigation verification,
and campaign analytics wiring remain CMS integration work. Do not add an unrelated
header/footer or a second analytics provider.

## Zeffy

The supplied thermometer is unmodified in size/source and is the only source of
live fundraising totals. The supplied v2 donation form and 450px iframe fallback
are included. A noscript iframe and an explicit same-campaign Zeffy recovery link
provide additional paths if the embed is unavailable. Zeffy's own form still
requires JavaScript to complete payment.

All campaign CTAs point to `#donate`; native anchors move focus to the donation
section. Giving choices are explanatory. Visitors choose amount/frequency in the
official form. At verification, Zeffy defaulted to $50 one-time and exposed $8 and
monthly giving. Change defaults in Zeffy if desired; do not fake selection in the
outer page. No donation was submitted during QA.

## QA performed

- `/8for8` resolved; homepage teaser and campaign CTA navigation worked.
- Browser widths 320, 375, 390, 430, 768, 1024, 1440, 1920: no outer-page or
  element horizontal overflow. Mobile form visually inspected at 320px.
- Desktop full-page/hero and 390px hero reviewed. Layout reserves donation space;
  the vendor resizes its own iframe as form content changes.
- Live thermometer and donation form loaded; $8/monthly selection verified.
- Script failure simulated with an ephemeral local fixture: the exact supplied
  onerror handler revealed the 450px fallback, populated its source, and loaded
  the live donation form. Fixture removed afterward.
- Keyboard activation and native anchor focus verified. Focus outlines, 48px
  CTA targets, decorative aria-hidden treatment, iframe titles and reduced-motion
  CSS included. Browser zoom/text resizing are not disabled.
- Static checks passed for a single H1/main, heading structure, unique IDs,
  section labels, fragment targets, local files, iframe titles, and absence of
  a homepage donation embed.
- Text palette contrast checked: minimum 4.55:1, including muted text on lavender.
- `node --check 8for8/campaign.js`, `git diff --check`, and the repository's existing
  `node press/build.mjs` passed; the Press build produced no unrelated changes.
- No first-party script errors observed. Zeffy/Cloudflare reported third-party
  telemetry/Turnstile warnings and console errors in the local browser. Full
  payment completion and vendor-internal WCAG compliance are not certified.

There is no application build, dependency manifest, or general lint/test suite
in this static repository. Repeat live payment-provider and theme checks on staging.

## Archiving

Nothing automatically hides or deletes this campaign. After November 2026, remove
or replace the marked homepage teaser and its scoped CSS. Keep `/8for8` as an
archive with updated copy/metadata and remove the embed if donations are closed.
If removing the page, configure a permanent redirect to an appropriate existing
SBF giving page before deleting files. Remove the page-specific asset enqueues.
